# Client：TGTO Chrome 扩展

解压 Client.zip，在 Chrome 的 `chrome://extensions` 打开开发者模式，选择“加载已解压的扩展程序”，指定包含 manifest.json 的 Client 目录。更新已有扩展时覆盖原扩展目录后点击“重新加载”，保留原来的扩展和采集数据。

打开扩展会自动免令牌连接 localhost 8765 的 Serve。进入已登录的 WPK 牌桌，在侧栏选择标签页并点击“开始采集”；附着之前的事件无法补取。八人完整参与、本人手牌、公开行动与筹码、蘑菇账本、策略覆盖及最低反馈检查都通过后才显示行动、支付金额与动作频率。停止、断线、换手和超时会清除建议；均匀平均且遗憾全零的节点显示“训练反馈不足”。该检查不是策略质量认证。

0.7.2 为预览：翻前使用两手视野的 Pluribus 分桶平均策略；翻后可协商最多 1.5 秒的全范围限时搜索，成功时按最新完整迭代行动，覆盖／预算不足时只回退到通过检查的当前节点平均策略。模型来源会标注“最新完整迭代”，这不保证优于平均策略。搜索是当前决策根的近似，后续策略仍缺覆盖；画像尚未用于调整行动。不覆盖 re-straddle、4–7 人或所有八人局面。频率不是胜率，也不是最优性认证。正式 V1.0 仍待真实八人验收。
