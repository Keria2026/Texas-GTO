# Client：TGTO Chrome 扩展

解压 Client.zip，在 Chrome 的 `chrome://extensions` 打开开发者模式，选择“加载已解压的扩展程序”，指定包含 manifest.json 的 Client 目录。更新已有扩展时覆盖原扩展目录后点击“重新加载”，保留原来的扩展和采集数据。

打开扩展会自动免令牌连接 localhost 8765 的 Serve。进入已登录的 WPK 牌桌，在侧栏选择标签页并点击“开始采集”；附着之前的事件无法补取。八人完整参与、本人手牌、公开行动与筹码、蘑菇账本和策略覆盖都通过校验后才显示行动、支付金额与动作频率。停止、断线、换手和超时会清除建议。

0.6.1 为预览：当前建议来自两手视野的 Pluribus 分桶平均策略，尚无实采在线搜索或画像剥削；不覆盖 re-straddle、4–7 人或所有八人局面。频率不是胜率，也不是最优性认证。正式 V1.0 仍待真实八人验收。
