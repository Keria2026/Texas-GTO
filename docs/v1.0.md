# V1.0：可实际运行的训练与实时决策版本

状态：开发中，尚未发布。用户已明确 V1.0 **必须包含实局实时行动推荐**。当前部署目标沿用 Windows Chrome 客户端与 WSL2 本地算法服务；后端安装包须可移植。公网多用户服务需要另外完成身份隔离及部署配置，不能直接暴露本机免令牌服务。

当前阶段交付为 **Pr1.0**，范围和验证见 [Pr1.0 说明](pr1.0.md)，不等同于完整 V1.0。已完成能力、剩余开发任务、执行顺序和发布关卡统一维护在 [V1.0 Roadmap](../ROADMAP.md)。本页保留产品约束与历史验证记录，历史段落中的“尚未接通”及轮数均只代表当时状态。

固定资源约束：用户允许最多 1G 内存，按 1 GiB 执行。API 与训练子进程的合计内存由 systemd `MemoryMax=1G` 限制，worker 另保留原有地址空间限制。Chrome／Vite／整个 WSL 不计入算法服务额度。持续训练必须在该预算内解决存储与计算问题；旧 JSON 导入的 64 MiB 限额独立保留；核心训练改为 SQLite 增量持久化，单轮工作集也使用有界缓存与独立临时数据库。

## 必须交付的完整链路

1. Chrome 采集 WPK 真实牌局，持久保存后上传；断线重发去重，重连与换手不串状态。
2. 服务按真实事件形成可回放牌局和学习样本；缺失字段、漏事件、未对账结算有明确质量标记。
3. 收集玩家行为画像，展示样本数和时间范围；可靠身份建立之前按采集来源隔离，不能把不同人的 `player-1` 合并。
4. Pluribus 主线自博弈空闲训练、暂停、保存和恢复，训练工件可导入导出，训练进度及故障可见。
5. 从当前局面、筹码、位置、私牌、轮次和可用画像计算实时行动建议；返回合法动作、金额、模型与状态版本，前端丢弃过期结果。
6. 可安装部署、自动启动、恢复故障、备份和回滚，真实对局验证通过后才标记正式 V1.0。

## 真实牌局如何参与学习

公开行动可用于学习按局面条件变化的行为分布；清楚标记机会分母时才能统计 VPIP/PFR 等指标。某街道观察到的弃牌次数不能直接解释为面对当前下注的弃牌概率，未亮牌不能标成诈唬。

学习样本冻结在当时的决策前上下文。后补行动金额可以更新同一事件版本，但未来公共牌和最终结算不能回填为当时已经知道的信息。结算标签与动作记录分开；真实记录只有已采取行动的结果，没有其他动作的反事实收益，不能直接当作 CFR 遗憾更新数据。

自博弈策略、观察得到的行为模型和独立评测各自有版本与来源。新样本进入统计不等于策略收益已经改善；候选策略须通过留出样本和独立对照后才用于推荐。

2026-11-03 更新：0.7.2 已接通八人完整参与场景的平均策略查询与翻后限时搜索、独立建议推送、实际金额、来源及版本绑定；计算不阻塞新事件接收，侧栏清除过期和迟到结果。局部搜索区分最新完整迭代的行动策略与累计平均，未覆盖或均匀平均且遗憾全零的 blueprint 节点受到拒绝检查；该检查不证明收益反馈充分。真实策略库仍缺覆盖，搜索尚未从下注轮起点重求解，画像未用于推荐；真实八人和策略质量尚未验收。详见 [八人建议预览](eight-player-recommendations.md)。
