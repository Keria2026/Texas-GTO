# 八人局行动建议：0.6.1 预览

本版接通 WPK 业务事件 → 公开下注回放 → 已训练平均策略查询 → WebSocket 推送 → Chrome 侧栏。它是 V1.0 的可部署预览，尚未完成真实八人牌局和策略质量验收。用户已选择稍后开始八人实局，先完成代码与插件包。

## 建议的实际来源

查询同一套 Pluribus 自博弈核心的 SQLite 平均策略。每次查询固定一个已提交快照，返回模型摘要、累计迭代数和规则版本；不使用当前遗憾替代平均策略，不用均匀分布补齐未训练节点。模型使用两手视野、手牌与筹码分桶；当前实局路径尚未接入深度受限搜索，画像只展示统计，不调整行动。

推荐包含全部动作的策略频率，并按该分布稳定抽取一次主建议。同一个牌局、信息集和模型版本在重连后不会重新抽取。频率不是胜率，模型迭代数不是质量认证。

## 输出前的条件

- 本手八个物理座位都已确认缴费并参与，明确 20 分普通费用、40 分小盲费用以及 2/4/8 强制下注。完整八席下，由小盲的前一席唯一确定按钮。
- 已观察开局快照及完整行动序列，公共牌、当前行动者和现金通过公开规则引擎回放；轮到本人且两张手牌已知。
- 从已观察的整池奖励及其后的连续配对结算重建逐人蘑菇权益。本版使用观察投影中最近八手结算；无可信锚点或锚点已不在窗口内时，停止推荐。
- 以实际开局现金和旧权益建立新的两手计算窗口，按共享信息编码查询平均策略；缺失节点、动作不一致、资金冲突或不支持的强制下注均不给建议。
- 客户端可选动作须与引擎相容。WPK 原始 min/max_raise_reported 的口径尚未确认，不能作为实际 raise_to 使用；金额由已验证引擎计算。

当前不承诺覆盖 4–7 人参与、re-straddle、所有筹码／旧池组合、任意树外下注、长期蘑菇价值或所有翻后节点。特别是这些条件失败时，插件显示原因与空动作，而非“最优”建议。

## 协议与失效

双方通过 `capture_recommendations_v1` 协商独立的 `capture.recommendation` 消息，schema 为 `tgto.capture-recommendation/0.1`。旧版 `capture.state` 观察协议保持兼容，其 unsupported 字段不代表新推荐消息的状态。

建议绑定 source_id、hand_id、through_sequence。ready 包含 actions、selected_action、model、issued_at_ms、expires_at_ms、elapsed_ms 和 warnings。每项动作包含 action、label、probability、amount_delta（本次额外支付）和 raise_to（本街总额，仅加注／下注）。不输出未知 EV。

服务先提交并 ACK 事件，再查询策略；查询结束再次检查来源的最新版本。旧批次、未 ACK 的结果、换手、换来源、当前行动者变化、停止采集、断线和过期结果都不能继续显示。快照超过 15 秒或查询超过 500 毫秒不输出建议，单条建议最长有效 10 秒。插件收到业务变化即时清除建议，另每 200 毫秒检查到期。

0.6.1 将推荐计算与接收循环分开：每个连接最多一个在算任务和一个最新待算版本，新业务事件合作取消旧计算并替换待算版本；计算期间仍处理 ACK、状态和心跳。断线或协议错误会取消并回收计算，取消不能降级为成功建议。侧栏按钮刷新、定时刷新和事件刷新共用版本校验，迟到响应不能恢复旧建议。协议不变，0.6.0 客户端仍兼容。

后台 worker 重启会结束旧采集 epoch 并保留缺口；只有当前浏览器会话中仍保存了明确采集意图、原来源和同一个允许访问的标签页时，才建立新 epoch。明确停止后不会恢复；新 epoch 仍须等待完整牌局和可信蘑菇账本。页面导航仍停止采集。

## 已执行的验证

- 后端合成八席开局覆盖所有八种按钮旋转、具体投入与加注总额、缺平均策略、资金／行动冲突、过期、版本复核及旧客户端协商。
- 插件验证严格协议、ACK、过期、断线、迟到结果和来源隔离。跨仓库测试经过真实 Python WebSocket／SQLite、WASM 验证和持久队列；该测试模型明确使用合成权重，验证链路而非策略强弱。
- 现有真实自博弈库第 5850 轮的只读检查：合成“八人各 800 分、无旧蘑菇余额、翻前第一个决策”中，169 类起手牌全部命中，查询 p95 为 2 毫秒。仅代表这个场景，不能推广到整场牌局。
- 安装插件的 Chromium 验证金额显示、320/390/600 像素侧栏、断线／过期清除及采集恢复。后端 wheel 在源码之外验证，不使用 Windows 依赖。
- 0.6.1 用故意阻塞的计算验证心跳、新批次确认、只保留最新待算版本、旧结果丢弃、断线清理与只读快照释放；浏览器验证迟到的手动刷新不能恢复已清除建议。实际训练库第 5899 轮的合成后续搜索仍缺策略，研究层的重点抽样优化不作为当前线上建议来源。

本地 API 和训练子进程继续受 systemd 合计 1 GiB 上限约束。真实八人实局成功率、整体延迟、策略收益和剥削层仍待验收；本版不得标为 V1.0 完整上线。
